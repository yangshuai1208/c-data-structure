## 二、核心知识

栈是一种后进先出的数据结构：

```text
LIFO：Last In First Out
```

有效括号适合使用栈，因为最后出现的左括号必须最先与右括号匹配。

例如：

```text
{[()]}
```

执行过程：

| 字符 | 操作 | 栈内容 |
|---|---|---|
| `{` | 入栈 | `{` |
| `[` | 入栈 | `{ [` |
| `(` | 入栈 | `{ [ (` |
| `)` | 匹配并出栈 | `{ [` |
| `]` | 匹配并出栈 | `{` |
| `}` | 匹配并出栈 | 空 |

最终栈为空，因此字符串有效。

## 三、top 的含义

本程序中的 `top` 表示下一个可写位置，同时也等于栈中元素数量。

入栈：

```c
stack[top++] = current;
```

出栈：

```c
char left = stack[--top];
```

出栈前必须判断：

```c
if (top == 0U)
```

否则会发生栈下溢和越界访问。

## 四、动态内存

程序根据输入字符串长度申请栈空间：

```c
char *stack = malloc(capacity);
```

使用完成后必须释放：

```c
free(stack);
```

如果 `malloc()` 返回 `NULL`，说明内存申请失败，不能继续访问该指针。

## 五、测试用例

有效输入：

```text
""
"()"
"()[]{}"
"{[()]}"
```

无效输入：

```text
"(]"
"([)]"
"("
"]"
"abc"
NULL
```

## 六、复杂度

- 时间复杂度：O(n)
- 空间复杂度：O(n)

每个字符最多入栈和出栈一次。

## 七、容易出错的地方

1. 空栈时直接出栈。
2. 使用 `stack[++top]` 跳过第一个位置。
3. 扫描结束后没有检查栈是否为空。
4. `malloc()` 后没有判断空指针。
5. 函数结束前忘记 `free()`。
6. 把嵌套括号错误地使用队列处理。

## 八、面试总结

有效括号使用栈处理。遇到左括号时入栈，遇到右括号时检查栈是否为空，并判断当前右括号是否与栈顶左括号匹配。扫描完成后只有栈为空才说明所有括号完全匹配。算法时间复杂度为 O(n)，空间复杂度为 O(n)。
